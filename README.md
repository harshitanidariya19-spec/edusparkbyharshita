# EduSpark: Ignite Your Learning (59)

Create a modern, professional, and visually impressive educational technology website called “EduSpark”.

The website should be inspired by the functionality of leading online learning platforms, but it must have completely original branding, layout, colors, text, and design.

Target users are school students, college students, and competitive exam aspirants.

Create the following pages and sections:

HOME PAGE

A modern navigation bar with the EduSpark logo.

Navigation links: Home, Courses, Live Classes, Practice, Mentors, About.

Login and Sign Up buttons.

A powerful hero section with the heading:
“Learn Smarter. Build Your Future.”

Supporting text explaining that EduSpark provides structured courses, live classes, practice tests, and mentorship.

Two call-to-action buttons: “Explore Courses” and “Start Learning”.

Add an educational-themed visual or illustration on the right side.

Add statistics such as 50,000+ learners, 200+ courses, and 100+ expert mentors.

COURSES SECTION
Create attractive course cards for:

JEE Preparation

NEET Preparation

UPSC Foundation

GATE Preparation

B.Tech Computer Science

Class 10 and 12 Boards

Each course card should include:

Course image or visual

Course title

Short description

Number of lessons

Level

Rating

Enroll Now button

LIVE CLASSES SECTION
Show upcoming live classes with:

Class title

Mentor name

Date and time

Subject

Join Live button

PRACTICE SECTION
Create a section for:

Mock Tests

Daily Quizzes

Previous Year Questions

Coding Practice

Display progress indicators and attractive cards.

MENTORS SECTION
Show professional mentor cards with profile images, names, subjects, experience, and a “View Profile” button.

STUDENT DASHBOARD
Create a sample dashboard showing:

Welcome message

Learning progress

Courses enrolled

Upcoming classes

Recent test scores

Daily learning streak

Recommended next lesson

TESTIMONIALS
Add student reviews and success stories using fictional names and original content.

PRICING SECTION
Create three plans:

Starter – Free

Pro Learner – ₹499/month

Achiever – ₹999/month

Show features for each plan and highlight the Pro Learner plan as the most popular.

FOOTER
Include:

About EduSpark

Quick Links

Courses

Social media icons

Contact information

Copyright text

DESIGN REQUIREMENTS:

Use a modern EdTech design.

Clean, premium, student-friendly interface.

Use a visually attractive color palette with deep blue, purple, white, and subtle gradient accents.

Use modern typography.

Add smooth hover effects and subtle animations.

Use rounded cards and soft shadows.

Ensure the entire website is fully responsive for desktop, tablet, and mobile.

Maintain consistent spacing and alignment.

Make the interface feel like a real, production-ready EdTech platform.

Build the website as a polished multi-page application with working navigation between pages. Use realistic but fictional educational content and do not copy the branding, logo, text, or exact design of any existing company.
